# Distributed Shopping List System

A distributed shopping list application developed in Python to demonstrate concepts of distributed systems, layered architecture, RESTful communication, service scheduling, fault tolerance and data replication.

The application allows users to add items to a shopping list, view registered items and calculate totals. The system was designed with multiple business services, data services and MongoDB instances configured with replication to improve availability and resilience.

> Academic Project — Distributed Systems

---

## Features

- Add items to a shopping list
- View registered items
- Calculate total quantity and final value
- RESTful communication between services
- Dynamic service scheduling
- Multiple business and data services
- MongoDB data storage with replication
- Docker-based service management
- Fault tolerance and high availability

---

## Technologies

- Python
- RESTful APIs
- MongoDB
- Docker

---

## Architecture

The system was designed using a distributed and layered architecture composed of:

- Client application
- Scheduler service
- Business services
- Data services
- MongoDB databases with replication

The scheduler is responsible for selecting available services and databases, supporting operational continuity even in failure scenarios.
